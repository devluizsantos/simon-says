# 🟢 Simon Says

Um jogo de memória inspirado no clássico Genius, em que você precisa memorizar e repetir sequências de cores cada vez mais longas.

## 🎮 Sobre o projeto

O Simon Says é um jogo desenvolvido para praticar lógica de programação e criar uma experiência interativa baseada em memória e atenção.

A cada rodada, o jogo apresenta uma sequência de cores que o jogador deve reproduzir na ordem correta. Conforme o jogador avança, as sequências ficam maiores, tornando o desafio cada vez mais difícil.

## ✨ Funcionalidades

- 🎨 Interação com botões coloridos.
- 🧠 Sequências de cores geradas pelo jogo.
- 📈 Aumento progressivo da dificuldade.
- ✅ Verificação das respostas do jogador.
- 🏆 Contagem de pontuação ou rodadas.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/devluizsantos/simon-says.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd simon-says
   ```

3. Abra o arquivo `index.html` no navegador.

## 🎯 Objetivos de aprendizado

Este projeto foi desenvolvido para praticar:

- Manipulação do DOM com JavaScript.
- Arrays e gerenciamento de sequências.
- Estruturas condicionais e funções.
- Controle de eventos e interações do usuário.
- Gerenciamento de estados e progressão do jogo.
